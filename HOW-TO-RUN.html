Running IELTS 2026

Quick reference for starting the local prep app.

1

Open a terminal in the project folder

Only needed once per terminal session.

cd ~/claude-code/projects/IELTS\ 2026
2

Install dependencies

Only needed the first time, or after pulling changes that touch package.json.

npm install
3

Start the app

Run this every time you want to use it.

npm run dev
4

Open it in your browser

Vite prints this same address in the terminal once it's ready (about a second).

http://localhost:5173
To stop the app: go back to the terminal and press Ctrl+C. Closing the terminal window also stops it — the link goes dead until you run npm run dev again.
